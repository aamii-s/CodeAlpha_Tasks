# Network Intrusion Detection System

This project demonstrates a basic Network Intrusion Detection System using Suricata.

## Objective

To monitor network traffic and detect suspicious activity using Suricata rules.

## Tools Used

- Suricata
- Kali Linux
- Terminal

## Features

- Network traffic monitoring
- Rule-based detection
- Alert generation
- Log analysis

## Testing

ICMP traffic was generated using ping and the Suricata alert was verified in the logs.
