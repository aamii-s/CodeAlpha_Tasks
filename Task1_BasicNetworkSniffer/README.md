# Basic Network Sniffer

A simple network sniffer made using Python and Scapy. It captures network packets and displays basic information about the traffic.

## Features

- Captures network packets
- Shows source and destination IP addresses
- Shows the protocol used
- Displays packet details

## Requirements

- Python 3
- Scapy
- Kali Linux

## Installation

Install Scapy using:

```bash
pip install scapy
```

## How to Run

Run the program using:

```bash
sudo python3 network_sniffer.py
```
